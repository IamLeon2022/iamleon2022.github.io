# Siyang Lyu's homepage

A single-page academic homepage for https://iamleon2022.github.io/.

The website is plain HTML and CSS, with no package installation or build step.
GitHub Pages can serve the repository root directly from the `main` branch.

## Files

- `index.html`: biography, research interests, publication, and contact links.
- `styles.css`: desktop and mobile layout.
- `assets/favicon.svg`: browser icon.
- `.nojekyll`: serve the files without Jekyll processing.

## Portrait

The supplied USC graduation photo is stored at `assets/portrait.jpg`.
The portrait's framing is controlled by `.portrait img` in `styles.css`.
The original photo file is preserved without alteration.

## Publication resources

The paper, PDF, and BibTeX use the published ACL Anthology record. Add Code or Poster links to
`.paper-links` when their public URLs have been confirmed.
